# Kazakh Khanate: Zhekpe-Zhek — дорожная карта

Жанр: souls-like про батыра и нечисть казахской мифологии. Unreal Engine 5.8, C++.
Цель первого года: **вертикальный срез** — один батыр, одна локация, два рядовых врага, один босс.
Правило: этап считается закрытым, только когда выполнен пункт «Готово, когда». Сроков нет. Есть порядок.

---

## Этап 0 — Инфраструктура
Цель: больше никогда не терять работу.
- [ ] Установить Git, создать репозиторий, `.gitignore` для Unreal (Binaries, Intermediate, Saved, DerivedDataCache, .vs)
- [ ] Первый коммит
- [ ] `DEVLOG.md` — одна строка на сессию: дата, что сделали, что сломано
- [ ] Переименовать `MyMyCharacter` → `BP_MyCharacter`
- [ ] Свой `BP_GameMode` вместо шаблонного
- [ ] Починить открытие `.uproject` двойным кликом

Чему учишься: Git, структура проекта UE.
Готово, когда: проект клонируется на чистую папку и открывается.

## Этап 2 — Боевая основа (без анимаций)
Цель: удар и блок как состояния, а не заглушки.
- [ ] `IA_Attack` (ЛКМ), `IA_Block` (ПКМ), привязка через `Started` / `Completed`
- [ ] `enum class ECombatState { Idle, Attacking, Blocking, Staggered }` вместо двух bool
- [ ] Стамина: float, тратится на удар/блок, восстанавливается в Tick
- [ ] Вывод состояния и стамины на экран (`AddOnScreenDebugMessage`)
- [ ] Нельзя атаковать без стамины; блок падает при нуле

Чему учишься: enum, события ввода, Tick, отладка на экране.
Готово, когда: на экране видно, как ЛКМ переводит в Attacking, ПКМ держит Blocking, стамина падает и растёт.

## Этап 3 — Анимация
Цель: батыр двигается и бьёт, а не скользит.
- [ ] Anim Blueprint: Idle / Walk / Run через Blend Space
- [ ] Anim Montage удара, запуск из C++ (`PlayAnimMontage`)
- [ ] AnimNotify «окно удара» — момент, когда клинок «включён»
- [ ] Анимация блока (поза)
- [ ] Первый ассет-пак с оружием (бесплатный, Marketplace/Fab) — на замену манекену пока не тратим время

Чему учишься: AnimBP, State Machine, Montage, Notify, связь C++ ↔ анимация.
Готово, когда: удар выглядит как удар, а не как телепорт флага.

## Этап 4 — Враг и урон
Цель: есть кого бить, и он умирает.
- [ ] Рефакторинг: `ABaseCharacter` (здоровье, стамина, состояния) → `APlayerBatyr` и `AEnemyBase`
- [ ] Здоровье, `TakeDamage`, смерть (рэгдолл или анимация)
- [ ] Хитбокс: `SweepMultiByChannel` вокруг оружия в окне удара, попадание один раз за удар
- [ ] Блок снижает урон, удар в блок тратит стамину защищающегося
- [ ] Первый враг: `BP_Enemy_Warrior` (человек, для теста)

Чему учишься: наследование, коллизии, каналы трассировки, система урона.
Готово, когда: можно забить манекена-врага и он падает; блок спасает.

## Этап 5 — Мозги врага
Цель: враг сам подходит, бьёт, отступает.
- [ ] `AAIController` + Behavior Tree + Blackboard
- [ ] Восприятие (AIPerception: зрение)
- [ ] Поведение: заметил → подошёл → ударил → отошёл → повторил
- [ ] Lock-on камера на цель (souls-стандарт)
- [ ] Уклонение (dodge) с i-frames

Чему учишься: AI-подсистема UE, Behavior Tree, EQS (базово).
Готово, когда: дуэль 1×1 с ботом ощущается как дуэль.

## Этап 6 — Souls-петля и интерфейс
Цель: цикл «умер → возродился → снова».
- [ ] Смерть игрока, экран «Сен қаза таптың», возрождение у очага/мазара
- [ ] Респаун врагов при возрождении
- [ ] HUD на UMG: полоски здоровья и стамины, здоровье босса
- [ ] Второй тип врага: быстрый и слабый (напр. албасты — с обманкой/исчезновением)

Чему учишься: UMG, GameMode/GameState, сохранение состояния.
Готово, когда: можно сесть и играть 10 минут без чит-команд.

## Этап 7 — Босс и локация
Цель: жезтырнақ.
- [ ] Босс-класс с фазами (по здоровью), 3–4 уникальных атаки
- [ ] Арена босса
- [ ] Блокаут локации: степь + мазар/руины, путь до босса с рядовыми врагами
- [ ] Музыка/звук боя (бесплатные библиотеки)

Чему учишься: дизайн боссов, левел-дизайн, блокаут.
Готово, когда: босс убивает тебя раз десять, а потом ты его — и это честно.

## Этап 8 — Вертикальный срез
Цель: показать людям.
- [ ] Главное меню, пауза, настройки чувствительности
- [ ] Эффекты попадания, кровь/искры, screen shake
- [ ] Packaged build (.exe), проверка на чужом компьютере
- [ ] Трейлер 60 секунд для ТикТок/YouTube
- [ ] Страница в Steam — обсуждаем, когда дойдём

Готово, когда: незнакомый человек скачал, поиграл, дошёл до босса, не задал вопрос «что нажимать».
